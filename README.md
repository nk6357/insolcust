# INSOL для заказчиков

Клиентский лендинг INSOL для подбора AI‑разработчиков и интеграторов. Дизайн и анимационная система основаны на фирменном сайте `insol-dvlp.ru`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm test
```

Статическая сборка создаётся в `dist/client`. Для работы формы на Beget в корень сайта также загружаются `beget/send.php` и `beget/.htaccess`; почтовая конфигурация хранится отдельно от публичной папки, если структура хостинга это позволяет.

## Форма проекта

Форма отправляет письмо на адрес из `mail-config.php`. В обработчике предусмотрены CSRF‑токен, проверка источника, honeypot, серверная валидация, ограничение размера запроса и частоты отправки.
